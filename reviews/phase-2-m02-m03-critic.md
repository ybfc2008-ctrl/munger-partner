## 总裁决

| 候选 | 裁决 | 核心理由 |
|---|---|---|
| `M02` 激励机制 | `ADVANCE` | 跨 1995/2002/2015/2019 的重复真实，存在独立的制度与行为检查功能，不能被 M01 无损替代；须按本报告收窄原理、标明推断并分层 B/C。 |
| `M03` 能力边界 | `ADVANCE` | 跨 2003/2017/2020/2022 的核心规则真实，能够在重大判断前形成独立的“是否具备判断资格”门槛，不能被 M01 或 M02 替代；须收窄行动扩展和动态边界措辞。 |
| `M02 ↔ M03` | `KEEP SEPARATE` | 一个检查“行为者实际被什么推动”，一个检查“判断者是否有能力理解”；两轴可交叉但不可无损合并。 |
| `M01 ↔ M02/M03` | `KEEP SEPARATE` | M01 是组织和选择模型的元方法；M02 是具体行为机制，M03 是认知资格门槛。M01 不能代替两者的触发问题和停止规则。 |

这里的 `ADVANCE` 表示候选已满足进入独立 Verifier 的实质门槛，不表示当前文字可以原样升级。下述机械修订是进入最终验证前的冻结条件。

## 一、模型集合中的功能位置

| 模型 | 它回答的独立问题 | 对决策的直接作用 |
|---|---|---|
| `M01` 多元思维模型格栅 | 我是否只用一个框架组织事实？ | 要求调用多个真正相关的学科模型，避免锤子找钉子。 |
| `M02` 激励机制 | 制度实际奖励什么行为，而不是口头要求什么？ | 发现目标与实际奖励错配，形成行为偏移的待验证风险。 |
| `M03` 能力边界 | 我和顾问凭什么有能力理解并判断这个问题？ | 把能力是否匹配纳入选择，必要时降低确信、补充学习、求助或暂缓。 |

三个模型处于不同层次：

- M01 决定“用哪些解释工具”；
- M02 解释环境中的行为压力；
- M03 检查使用工具的人有没有足够能力。

因此不能以“激励和能力都是 M01 格栅中的模型”为由删除它们。若这样处理，M01 会退化成包含一切的空泛总类，失去最小模型集合的区分能力。

## 二、M02｜跨时期重复是否真实

### 1995 B 级核心锚点

`CU-1995-PSYCH-0001` 直接把“reinforcement / incentives 的力量被低估”列为第一项心理误判，并记录 Munger 自称一生都低估它。这是最清楚的核心命题。

限制：

- Whitney Tilson 整理文本为 B，不是 Harvard 官方原稿；
- 精确日期和录音未确认；
- 它直接支持“激励力量常被低估”，不自动支持所有制度设计细节。

### 2002 C 级结构补充

`CU-2002-WESCO-0001` 记录 `reward A / say you want B` 的目标—奖励错配。这不是对 1995 文本的复制，而是给核心命题增加可执行结构：比较口头目标和实际奖励。

限制：Whitney Tilson 的具名现场笔记为 C、非逐字；`schizophrenia` 是比喻，不能医学化，也不能当作行为必然发生的证明。

### 2015 C 级边界补充

`CU-2015-DJCO-0001` 记录错误激励不必影响所有人，影响足够比例即可使制度结果恶化。它增加的是覆盖率边界，不是另一种新模型。

限制：Phil DeMuth/Forbes notes 为 C、非逐字；医疗支付语境不能自动推广成所有人的行为规律。

### 2019 B 级持续观点

`CU-2019-WSJ-0001` 在 Wells Fargo 讨论中记录：激励压力过强会使太多人屈从，管理层可能根本没想到自身激励制度有问题。它证明 Munger 在不同年代继续使用同一解释框架。

限制：WSJ 是 publisher-edited transcript；它不独立验证 Wells Fargo 的具体违规事实、管理层责任或排他因果。

### 结论

跨时期重复为真，而且不是同一转载链的机械重复：一次演讲、两次不同会议的具名现场笔记和一次编辑访谈分别保存了核心、结构、覆盖边界与持续观点。它们共同支持一个稳定模型，但不能共同变成“激励解释一切”的普遍因果定律。

## 三、M02 是否可被 M01 无损解释

**不能。**

M01 只要求不要用单一框架，并从多个学科组织事实；它没有告诉用户：

- 如何识别行为者的实际收益；
- 如何比较实际奖励与口头目标；
- 为什么制度参与者可能向 A 而不是 B 偏移；
- 何时把激励错配列为风险假设。

反过来，M02 也不替代 M01。即使发现激励问题，仍需结合能力、约束、文化、法律、竞争和其他模型，不能停止解释。

M02 的独立决策功能可以压缩为两问：

1. 这个制度实际上让什么行为更有利？
2. 实际奖励与公开目标是否一致？

只要这两问能改变事实收集、风险判断或行动选择，M02 就具有 M01 无法替代的功能。

## 四、M02 名称、原理与边界审核

### 名称

当前中文 `激励机制`、英文 `Incentives` 可以保留；名称足够短，也与 Munger 原词一致。不要扩张为：

- `激励决定行为`；
- `奖励决定一切`；
- `激励导致失败`。

这些名称会把风险检查写成充分因果。

若希望名称直接显示决策功能，只允许使用同义标题 `激励塑造行为` / `Incentives Shape Behavior`，不得同时保留为第二个一级模型或下设新 KU。

### 当前原理的问题

当前文字：

> 判断制度时，检查报酬、惩罚和衡量方式实际鼓励什么行为；口头要求不一定等于真实激励。

方向正确，但有两项需要收紧：

1. `惩罚和衡量方式` 没有在当前四条最短 L1 中直接出现，属于合理但未标记的制度设计扩展。
2. 没有区分 Munger 文本与项目决策规则，看起来像逐字来源结论。

### 原理精确替换文本

建议完整替换为：

> **项目决策规则（基于 B/C 级证据的抽象）：**判断制度时，先识别它实际奖励什么、使什么行为更有利，再与口头目标比较；若制度实际奖励 A 却要求 B，应把行为向 A 偏移列为待验证风险，而不是直接当作既成因果。

如果以后要恢复“惩罚、考核、衡量方式”，必须增加直接证据，或继续明确标作项目对 `incentives` 的操作化解释；不得悄悄写成原话。

### 边界精确替换文本

建议替换为：

> 激励是行为风险因素，不是行为的唯一、必要或充分原因。价值观、能力、约束、监督、法律和其他环境因素都可能改变结果。不能仅凭结果倒推某人必然受某项激励驱动；具体事件仍须证明“激励结构 → 行为变化 → 结果”，并保留其他解释。C 级材料只补充目标—奖励错配和“并非所有人都会受影响”的边界，不证明具体案例的排他因果。

这里列出的其他因素是项目因果边界，不是新增模型，也不应在本轮继续展开。

### 反例

当前 `待研究` 可以保留。本轮明确不涉及 Case，因此不能为了模型看起来完整而制造反例。必须保留后一句：当前没有用具体失败案例证明激励是主要或排他原因。

## 五、M02 B/C 来源使用审核

当前 `Corpus span` 把四条并列，容易让读者误以为证据同级。应机械增加来源分层，而不新增字段：

> **核心 B 级：**`CU-1995-PSYCH-0001`（激励力量被低估）；`CU-2019-WSJ-0001`（持续观点及激励过强风险，非 Wells Fargo 因果验证）。  
> **限定性 C 级：**`CU-2002-WESCO-0001`（奖励 A / 要求 B 的错配结构）；`CU-2015-DJCO-0001`（影响不必覆盖所有人）。两条均为具名非逐字现场笔记。

`## 原话` 不应把四条笼统称为同质“原话”。建议改为：

> 见 `KU-0002` 及四条 L1。B 级文本承担核心观点锚定；C 级具名笔记只承担结构和边界补充，引用时必须保留“reported / non-verbatim”身份。

## 六、M02 最终裁决

理由：

- 有两条 B 级核心锚点和两条 C 级限定补充；

1. 用上文精确文本替换原理和边界；
2. 增加 B/C 分层；
3. 保持反例为空与因果警示；
4. 不建立 Case、不新增模型；
5. 不把 Wells Fargo 或医疗支付写成已验证失败案例。

## 七、M03｜跨时期重复是否真实

### 2020 B 级核心锚点

`CU-2020-CALTECH-0001` 两次直接表达知道自己哪里有能力、哪里没有，以及能力边界。这是 M03 最清楚的核心文字。

限制：Caltech 官方活动/视频为 A，但当前选段尚未时间戳对齐；当前文字按 B，不得把 L1 本身称 A。

### 2022 B 级决策补充

`CU-2022-DJCO-0001` 直接要求把本人或顾问的能力水平纳入投资方式选择。它给 M03 增加了独立决策功能，不只是重复“知道自己不知道”。

限制：Richard Lewis 具名 transcript 为 B，主持人问题是概括而非逐字；它不证明任何投资风格普遍最优。

### 2017 B 级动态边界补充

`CU-2017-DJCO-0001` 的问题明确询问 Circle of Competence 是否会扩张、收缩或重画；回答指出复杂系统中的经验法则可能随时间失效，人必须面对不确定性。

这条只支持“旧经验法则可能失效、边界需要复核”，不直接证明能力圈必然扩大、收缩，也不给出固定重估周期。

### 2003 C 级范围风险补充

`CU-2003-WESCO-0001` 记录扩大资产和企业搜索范围会增加越出能力圈的风险。它支持“扩大搜索范围不等于能力已经扩大”。

限制：Whitney Tilson 具名现场笔记为 C、非逐字且按主题重组；不能用它证明范围越广结果必然越差。

### 结论

跨时期重复为真。核心能力边界在 2020、2022 得到两条独立 B 级表达；2003 C 和 2017 B 分别补充搜索范围与时间变化边界。四条不是同一文本的重复转载，但后两条只能作边界，不能被写成新的核心命题。

## 八、M03 是否可被 M01 或 M02 无损解释

### M01 不能替代 M03

一个人可以调用多个学科模型，却仍不了解具体行业、技术、法律、会计或事实材料。M01 解决框架单一，M03 解决判断资格不足；使用更多模型本身不能证明能力。

M03 还能在 M01 运行前后触发停止或降级：如果本人和顾问都无法说明能力依据，就不应仅因为已经列出多个模型而形成高确信判断。

### M02 不能替代 M03

二者检查不同失败源：

- 某人可能能力很强，但因报酬结构产生利益偏移；
- 某人也可能动机完全一致，却没有理解问题的能力；
- 两者还可能同时存在。

因此 M02 与 M03 不应 `MERGE`。合并为“评估人”会丢失一个检查动机、一个检查能力的精确触发器。

## 九、M03 名称、原理与边界审核

### 名称

英文 `Circle of Competence` 准确。中文建议从泛化的 `能力边界` 收窄为：

> `能力圈边界`

这样既保留通行概念，又强调本模型检查的是“在哪些问题上具有可靠判断能力”，不是一般职业技能清单。若项目已决定沿用 `能力边界`，也可保留，但不得另建“能力圈”同义模型。

### 当前原理的问题

当前文字把“行动、学习、求助或放弃”四种响应直接放入模型原理。它们是合理的产品决策选项，但四条 L1 直接支持的是：识别能力边界，并把本人或顾问的能力纳入选择。来源没有逐项规定这四种动作。

`知识、经验和判断能力` 也是对 competence 的项目展开，应标作抽象，而非原话。

### 原理精确替换文本

建议替换为：

> **项目决策规则（基于 B/C 级证据的抽象）：**面对重大判断，先评估本人或顾问是否具备与问题匹配的实际理解和判断能力，并把这一评估纳入选择；不能说明能力依据时，不把熟悉感、自信或扩大搜索范围当作能力已经存在。

“学习、求助、缩小行动或暂缓”可在 Decision Engine 中作为响应选项，但不应在模型原理里冒充 Munger 直接规定的完整动作清单。

### 边界精确替换文本

建议替换为：

> 能力圈不是永久身份，也不能用来合理化拒绝学习。2017 年 B 级文本只支持：复杂系统与环境变化可能使过去有效的经验法则失效，因此既有边界需要复核；它不证明边界必然扩大或按固定周期变化。2003 年 C 级笔记只支持：扩大机会搜索范围会增加越界风险，不等于能力已经扩大。**项目校准规则（AI 推断）：**边界判断本身可能过度自信或过度保守，应尽量用相关经验、可验证表现和持续反馈校准。

这段保留了现有合理边界，同时把来源事实与项目推断分开。

### 反例

当前 `待研究` 和“没有独立结果案例”的警示应保留。本轮不涉及 Case，不应把任何投资成败拿来事后证明能力圈。

## 十、M03 B/C 来源使用审核

应把四条来源分层：

> **核心 B 级：**`CU-2020-CALTECH-0001`（直接能力边界）；`CU-2022-DJCO-0001`（本人/顾问能力进入选择）。  
> **动态边界 B 级：**`CU-2017-DJCO-0001`（复杂系统的旧经验法则可能失效；不证明固定变化方向）。  
> **限定性 C 级：**`CU-2003-WESCO-0001`（扩大搜索范围增加越界风险；具名、非逐字、按主题重组）。

`## 原话` 建议改为：

> 见 `KU-0007` 及四条 L1。2020/2022 B 级文本承担核心模型锚定；2017 B 级只补动态边界；2003 C 级只补搜索范围风险。不得把四条当作同等强度、同一命题的逐字原话。

出处还应保持现有限制：

- Caltech 官方视频存在不等于当前 transcript 摘录已经 A 级对齐；
- 2022、2017 仍按 B；
- 2003 保持 C，不升级。

## 十一、M03 独立决策功能

M03 的触发问题可以压缩为：

1. 这个判断需要哪些具体能力？
2. 我和顾问凭什么证明具备这些能力？
3. 现有经验是否仍适用于当前环境？

它能产生 M01/M02 不会自动产生的决策结果：降低确信、缩小判断范围、补足知识、寻找合格帮助或暂缓选择。这里的响应是项目操作化，不是新增模型，也不是历史结果因果结论。

## 十二、M03 最终裁决

**`ADVANCE`。**

理由：

- 两条 B 级核心锚点足够清楚；
- 一条 B 和一条 C 提供真实而有限的边界增量；
- 与 M01、M02 均不重复；
- 有明确的重大判断触发器和降低过度自信的功能；
- 当前过度扩展可用机械改文修复，不需要新结构。

进入 Verifier 前必须：

1. 名称改为 `能力圈边界`，或明确 `能力边界` 是该名称的唯一中文规范名，禁止再建同义模型；
2. 用上文精确文本替换原理和边界；
3. 增加 B/C 功能分层；
4. 将行动选项和校准标准标为项目规则/AI 推断；
5. 不把 2017 写成边界必然变化，不把 2003 写成扩大范围必然失败；
6. 不新增 Case、KU 或模型。

## 十三、互相重复与压缩率最终检查

M02 和 M03 不能合并成“评估人和制度”的大模型。合并会造成两个损失：

1. 动机与能力被混淆。一个判断错误可能来自利益冲突，也可能来自真诚无知；两者需要不同证据。
2. 决策动作被混淆。M02 要求重看奖励结构和行为数据；M03 要求重看判断资格、经验与知识缺口。

同时，不应在它们下面再新建这些一级同义模型：

- `奖励 A 要求 B`、`激励偏差`、`激励导致行为`：统一属于 M02 的解释或触发方式；
- `能力圈`、`知道自己不知道`、`顾问能力`、`动态能力边界`：统一属于 M03 的解释或边界。

这能维持当前目标：用三个真正不同的模型承担三个不同的决策功能，而不是把相邻措辞扩张成更多一级模型。

## 最终结论

M02、M03 都值得进入下一道独立 Verifier，不应 `HOLD`、`MERGE` 或 `REJECT`。它们通过的理由不是“芒格多次说过”，而是同时满足：

- 跨时期证据真实且来源独立；
- B 级核心锚点足够，C 级只承担有限补充；
- 与 M01、彼此之间无法无损替代；
- 能提出不同的、会改变决策流程的问题；
- 因果边界能够明确冻结。

最终升级前只需收紧现有 Markdown 文本，不需要新增系统、字段、Agent、Case 或自动化。
