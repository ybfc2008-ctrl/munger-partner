## KU-0002｜激励的行为力量容易被系统性低估

**裁决：`PASS`**

- 来源与归属：Whitney Tilson 整理的演讲 transcript 不是 Harvard 官方原稿或已对齐录音，标 `B` 正确。L0 已明确这一限制。
- 定位：printed p. 3 / file page 2 / item 1，配合公开 PDF 足以复现；私有行号不是唯一定位。
- 上下文：两个片段属于同一连续论述。标题“Under-recognition”与 Munger 自述“一生都低估”共同支持“容易被持续低估”，没有伪造群体效应大小。
- 翻译：`reinforcement / incentives` 译作“强化 / 激励”准确；“我一生都低估了它”忠实。
- 推断与因果：制度分析是明确标注的 `AI 推断`；边界也明确禁止从结果反推激励，未把相关性冒充因果。
- 重复：不重复 `M01`。与 `KU-0003` 有上下位关系风险，但本条是一般激励证据，当前不构成重复模型批准。

**最小必要修改：无。** `translation_status` 仍须保持 `ai_draft`，本裁决也不授权创建模型。

## KU-0003｜持续的交易压力会损害等待的能力

**裁决：`REVISE`**

- 来源与归属：Berkshire 官方 2014 Annual Report 中由 Charles T. Munger 署名的文章，printed p. 42 可复现，标 `A` 正确。
- 短引文与翻译：三个片段均来自同一段，译义基本准确；`helpers` 在此语境更接近“顾问或协助交易者”，但现译不构成误引。
- 主要缺陷：原文是在回答“为何 Berkshire 的收购结果很好”，属于 Munger 对自身组织的回顾性归因，不是不同收购制度的对照研究。标题中的“会损害”把候选机制写成确定因果，强于证据。
- 未经证明的因果：原文同时列出无收购部门、无偏向交易的顾问、Buffett 的经验与自制、耐心等多项因素；不能从这一段识别“交易压力”单独造成的效果。
- 重复：不重复 `M01`，但它很可能是 `KU-0002` 的具体应用。除非以后证明其新增的是独立机制，否则不得据此另建一个一级模型。

**最小必要修改：**

1. 把标题和原理中的确定因果降为条件性警报，例如“交易压力可能降低拒绝交易的门槛”。
2. 在“原理”中明确：这是由 Munger 的回顾性解释提出的候选机制，不是已完成因果比较的结论。
3. 保留现有反例与边界；模型映射继续留空，不新建模型。

## KU-0004｜一阶结论正确，不代表总体判断正确

**裁决：`REVISE`**

- 来源与归属：Michigan Ross 官方录影、活动信息及多份公开 transcript 相互支持归属；因工作 transcript 尚未对齐官方视频时间戳，标 `B` 合理，不得升为 `A`。
- 定位不足：`Drive transcript normalized extraction lines 400-414` 对公开仓库审阅者不可复现；YouTube 链接又没有时间戳。当前定位不能满足“一键回到证据”。
- 上下文不足：短引文准确，翻译也准确，但只保留了“一阶 / 二阶”标签。原话是在讨论 Ricardo、自由贸易以及中美相对增长与国力的具体判断，而不是一条已经独立验证的一般定律。
- 事实边界：Candidate 已写“当前不把 Munger 对中美贸易的具体判断当作已经验证的案例”，这一限制必须保留。Munger 对两国增长、相对国力和政策必然性的判断只能作为他的观点，不能进入 Verified 事实层。
- 推断：把它抽象为“评估后续反馈和适应”可以作为 `AI 推断`，但应避免让读者误以为源材料验证了所有“二阶后果”分析。
- 重复：不重复 `M01`，与其余四条没有实质重复。

**最小必要修改：**

1. 为官方录影补精确时间戳；若暂时做不到，增加可公开复现的 transcript 段落定位，并保持 `B`。
2. 在 L1 加入最短必要语境，说明这是 Munger 对 Ricardo 与贸易的具体论述；不得把其具体中美结论写成已验证事实。
3. 保留“二阶后果需有传导机制、时间尺度和可观察结果”的边界。

## KU-0005｜主动用反证更新重要信念

**裁决：`REVISE`**

- 来源与归属：2020 Daily Journal 年会完整录影可作为 A 级原始来源；公开 transcript 也能交叉确认所引回答确由 Munger 说出。
- 等级错误：当前 L1 短引文实际取自 Drive 工作 transcript，且尚未与原始录影时间戳对齐。不能因“录影本身是 A”就把未对齐的文本片段标成 `A`。在完成对齐前，L1 与 Candidate 应为 `B`。
- 定位不足：Drive 行号对公开审阅者不可复现，YouTube 链接没有时间戳。
- 上下文与翻译：原问题明确询问如何用 disconfirming evidence 改变重要信念；三个片段与回答方向一致。`discard beliefs` 译作“丢弃信念”略生硬，但意思未错；“反证”应理解为削弱原判断的证据，而非严格逻辑反例。
- 推断与因果：主动更新信念的抽象有原文支持。Candidate 正确地没有把 Munger 关于出售错误投资、财富来源的自述当作可独立核验的成功因果案例。
- 重复：不重复 `M01`。`KU-0006` 的自我纠错叙述可成为本条的候选例子，但不能仅凭同一主题重复建模。

**最小必要修改：**

1. 在时间戳对齐前，将 L1 `source_level` 和 Candidate `source.tier` 从 `A` 降为 `B`；L0 可继续说明 A 级录影存在。
2. 补官方录影精确时间戳后，才可重新审查是否升回 `A`。
3. 中文可将“丢弃信念”改为更自然的“主动放弃原有信念”，但不得把 `ai_draft` 改成人工校验状态。

## KU-0006｜新渠道不会自动改写行业经济性

**裁决：`REVISE`**

- 来源与归属：2023 Daily Journal 年会录影及公开 transcript 能确认 Munger 关于线上零售、Alibaba 与失焦的自述。
- 等级错误：与 `KU-0005` 相同，当前摘录来自未对齐视频时间戳的工作 transcript。L1 与 Candidate 暂不能标 `A`，应为 `B`；L0 可以保留“A 级录影存在、文本待对齐”的分层说明。
- 定位不足：只有私有 Drive 行号，没有公开视频时间戳，公开复现链不完整。
- 翻译：三句译义基本准确；`people who are leading in the online retailing` 更稳妥的表达是“线上零售领域的领先者”，避免武断限定为某类企业。
- 主要过度抽象：原文直接证明的是 Munger 认为自己因 Alibaba 的线上零售地位而“着迷”、忽略其仍具有零售属性，并高估未来回报。它不能单独证明“新渠道通常不改变行业利润率、资本回报或竞争结构”。当前原理把一个投资者对一家公司的回顾性判断扩大成行业普遍规律。
- 未经证明的因果：Alibaba 的实际回报由竞争、估值、监管、治理、宏观环境等多因素共同决定；“仍是零售”不能被当成已经验证的损失原因。Candidate 的现有反例与边界正确，必须保留。
- 重复：不重复 `M01`；但作为“2022 年摧毁的想法”，它首先也是 `KU-0005` 的具体自述案例。若保留独立候选，必须只保留其关于“渠道标签不能替代具体经济性分析”的增量，而不是再做一条泛化的信念更新原则。

**最小必要修改：**

1. 在补齐官方视频时间戳前，将 L1 与 Candidate 的来源等级降为 `B`。
2. 把标题与原理收窄为检查规则，例如：“线上渠道标签本身不足以证明更好的竞争优势或未来回报。”
3. 删除或降格“新渠道不会自动改写行业经济性”的普遍经验断言；利润率、资本回报与竞争约束只能作为待检查项目，不能冒充该个案已经证明的结论。
4. 明确与 `KU-0005` 的重叠风险；不得据此创建新模型。

## 跨条目结论

1. 五条均未重复 `M01`，但 `KU-0003` 与 `KU-0002`、`KU-0006` 与 `KU-0005` 存在明显上下位或例证关系；后续应优先归并，不扩大模型数量。
2. 来源等级必须落在“当前摘录实际可核验的证据链”上，不能用 A 级视频的存在替未对齐工作 transcript 升级。
3. Munger 的本人回顾可以可靠证明“他这样解释自己的经验”，不能自动证明该解释具有排他因果性。
4. 本报告不授权任何 Candidate 迁移到 `/verified`；`PASS` 的 `KU-0002` 仍需独立 Verifier 作最终裁决。
