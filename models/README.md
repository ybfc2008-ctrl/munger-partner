# L2 Models

The canonical core-model list is deliberately small. A new model requires proof that no approved model can explain the mechanism.

## Approved core models

- `M01` — 多元思维模型格栅 / Latticework of Mental Models

“跨学科思维”“锤子与钉子”“多模型思考” are subordinate concepts or explanations of `M01`, not separate top-level models.
