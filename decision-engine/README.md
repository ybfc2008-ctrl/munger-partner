# L4 Decision Engine

The engine starts with inversion: if the decision ends badly, what is the most likely cause? It then checks facts, competence boundaries, a small number of approved models, structurally similar failures, disconfirming evidence, incentives, second-order effects, ruin risk and margin of safety.

Outputs must label `Evidence`, `Inference`, `Case` and `Judgment`. Engine output never mutates L0 or L1.
